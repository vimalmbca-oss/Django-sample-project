# 📝 Django Blog Website
A dynamic Blog Web Application built using Django (Python).
This project allows users to browse blog posts, view detailed articles, navigate through pages using pagination, and contact through a contact form.

---

# 🚀 Features

- 📰 Blog Post Listing Page
- 📄 Detailed Post View Page
- 🔍 Search Bar UI
- 📑 Pagination (Multi-page navigation)
- 🗂 Category Display (Art, Technology, Science, Sports, Food, etc.)
- 📌 Related Posts Section
- 📬 Contact Form Page
- 🧭 Navigation Menu (Home, About, Contact, Admin)
- 🎨 Responsive UI Design

---

# 🖥 Pages Overview
## 1️⃣ Home Page
- Displays all blog posts
- Shows post image, title, short description, category
- Includes pagination for multiple pages
- Search bar interface

## 2️⃣ Detail Page
- Full blog content view
- Published date
- Featured image
- Related posts sidebar

## 3️⃣ Contact Page

- Contact form with:
   - Name
   - Email
   - Message
- Submit button
